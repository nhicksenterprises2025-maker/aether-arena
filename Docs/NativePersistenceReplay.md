# Native persistence and replay contracts

The native profile is `%LOCALAPPDATA%/RiftCrownArena/ue_save.json`, with the existing command-line/environment save-root overrides retained. Native schema 1 can import valid browser `player_save.json` profile and five deck presets. Browser source files are preserved, their checksum is recorded, and unknown root/profile/preset/settings extension fields survive compatible native saves. Invalid preset cards cannot replace valid defaults, duplicate preset IDs use the first valid record, names are sanitized, counters saturate, and settings are normalized to finite supported values.

Writes create unique UTF-8 staging files, preserve the prior file as `.bak`, and use Windows `MoveFileExW` replacement with write-through. Recovery moves a corrupt primary into `Backups` before saving the recovered backup so a failed replacement cannot destroy the known-good backup. A future schema in either primary or backup disables profile writes and edits. Native profile reads are limited to 1 MB.

Native replay format 1 uses the `rift-native-1` model identity. Opening/importing first checks the entire recording: format/model, finite bounded duration, all snapshots, canonical card IDs, legal team/entity enums, complete hand/queue/deck shapes, finite numbers and bounded arrays, monotonic snapshot/event times, ordered event sequences, and valid result analysis. Invalid or future recordings leave the current replay and source file intact. Replay files are limited to 64 MB.

Snapshots serialize all public native state, including AI observed cycles and decisions, card telemetry and its denominators, targeting/status ownership and timers, navigation/debug state, projectiles with damage/splash/cast attribution, and stationary hazards with cast/tick timing. Deserialization builds a temporary snapshot and commits only after successful validation. Optional new fields retain compatibility with earlier native format 1 recordings; unsupported browser replay archives remain preserved.

Each recorded sample bookmarks the latest observed event sequence. Playback starts from the latest sample at or before the requested time, applies later deploy/damage/status/phase/DEV events, advances resource and decay clocks, and interpolates surviving entity positions toward the next sample. This preserves immediate events between position samples without smearing card spending. Position interpolation is presentation; recorded native samples and events remain authoritative evidence. Forward playback broadcasts only newly crossed events through the regular match event delegate for VFX/audio; seeking rebuilds state and moves the cursor without replaying historical sounds.

Run `Build/Test-Unreal.ps1 -Filter Rift` after building the Editor target and importing the project content. The runner creates a fresh isolated save root under `Build/Automation`, waits for the automation queue to finish, and checks the exported JSON report. `Rift.Integration.ProfilePersistence` covers migration/extensions/settings, atomic writes, corrupt-primary recovery and future-schema protection. `SnapshotRoundtrip` verifies full public-state roundtrip and malformed-field rejection without partial mutation. `ReplayTimeline` checks record/open/seek/immediate spell deaths/DEV mutation/import rejection/cursors. `CardData` loads every imported card asset and verifies canonical combat values plus mesh/art/animation/effect/sound bindings. These tests require `-RiftAutomationSandbox` to prevent persistence fixtures from touching player data.
