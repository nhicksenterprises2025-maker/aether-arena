# Rift Crown Arena 1.3.3

Fixed ground troops getting stuck behind Core and Guard Towers. Ground deployments near occupied structures start in nearby clear space, and units route safely around tower edges. Paid ground drops at arena edges also start inside their body clearance, eliminating a first-frame position snap. Card costs, troop counts, combat stats, flying units and spell behavior are retained.

Existing Meta Lab datasets stay available as history. New matches use a separate navigation fingerprint so results from the older pathing rules are kept distinct.
