Rift Crown Arena v12.10 — Freeze + Balance Update

FREEZE / PERFORMANCE FIXES
- Fixed a Frost Fang runtime crash caused by an uninitialized forward-direction reference in the ambient frost-breath animation.

- Meta Lab simulation automatically pauses while a live match is running and resumes in menus.
- A* bridge congestion is snapshotted once per path calculation instead of rescanning every live unit for each explored node.
- Reduced worst-case A* expansion budget and slightly relaxed routine repath frequency to reduce main-thread spikes.
